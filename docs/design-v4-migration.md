# Перенос SupportOS HTML v4

Источник: пользовательский архив `supportos-html-template-v4.zip`.
Область: оформление рабочих страниц и новые функции инструкции к бинду, AI-проверок и обработки обратной связи. Демонстрационные данные не добавляются в приложение.

## Выполнено

- Общая типографика, поверхности, карточки, таблицы, кнопки и отступы рабочих страниц.
- Компактная верхняя панель и переходы Workspace / QC / Admin с существующими проверками прав.
- Боковая навигация QC, ссылки на предложения и режимы управления справочниками сохранены.
- Рабочие справочники остаются без дополнительной боковой навигации.
- Просмотр бинда: закреплённый контекст на широких экранах, отдельный блок готового ответа, копирование, язык и результат существующей автопроверки.
- Общие бинды используют то же оформление блока ответа.
- Быстрый переход в мониторинг с проверкой разрешений.
- Карточки активности, обзор контента, страницы настроек и мониторинга.
- Ширина дерева 290 px; ширина помощника по умолчанию 336 px. Сохранённые пользовательские размеры помощника продолжают применяться.

## Дополнительные функции

- Внутренняя инструкция для каждой языковой версии бинда: создание, редактирование, история и сравнение предложений. Инструкция отображается отдельно, передаётся помощнику и не включается в копируемый готовый ответ.
- Выбор темы обращения в помощнике влияет на применимость правил и знаний. Изменение темы или исходного материала сбрасывает устаревшую проверку ответа.
- AI-контекст подбирает опубликованные материалы по запросу и теме, сохраняет ограничения проекта/языка. Правила и проектные инструкции не обрезаются молча. Командный глоссарий имеет приоритет над локальным.
- Playground показывает реально использованные источники и версию настроек. Публикация доступна после проверки применившегося черновика.
- Тесты запускают независимые ответы Production и Draft, показывают улучшения и ухудшения по заданным фразам, продолжают работу при ошибке одного сценария, поддерживают отмену и экспорт отчёта. Пустой ответ или тест без условий не получает Pass.
- Обратная связь: фильтры, частые причины проблем и создание черновика материала, правила или теста. Оценки сами по себе не обучают модель.

## Проверки и ограничения

- Общий прогон: 209 тестов приложения и 1 временная проверка статического рендера прошли. Затем добавлены ещё 2 проверки внутренних инструкций; повторный целевой прогон — 25 тестов прошли.
- TypeScript и production-сборка проходят. Biome для изменённых файлов: ошибок нет, остаются предупреждения существующего кода.
- Для проверки компоновки временно построены 27 статических экранов из реальных React-компонентов с тестовыми данными. В браузере проверены Workspace, QC, AI-админка, настройки, а также мобильная компоновка при ширине 390 px; исправлены тесный заголовок, поля помощника и ширина меню админки.
- Это не заменяет проверку рабочих экранов с загруженными серверными данными: часть статических страниц отображала состояние загрузки. Временные HTML и распакованный прототип удалены из проекта.
- Полная визуальная приёмка и сквозные действия под рабочим аккаунтом остаются отложенными по согласованию с пользователем: доступный сеанс не имеет прав Workspace/QC/Admin. Авторизация не менялась.
- Вызовы реального AI-провайдера и оценка качества на рабочих сценариях не выполнялись. Улучшена проверяемая логика подбора контекста и контроля изменений; фактическое качество ответов нужно измерять сохранёнными тестами и ручной оценкой.
